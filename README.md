# muhzain.me

Source for my personal portfolio website: **[muhzain.me](https://muhzain.me)**.

The site is a client-side React application for presenting projects, experience, education, a resume view, and technical write-ups.

## Stack

- React 18
- Vite 5
- React Router
- Tailwind CSS 4
- Framer Motion
- Lucide React
- Radix UI toast primitives

## Site structure

The current source includes routes for:

- <code>/</code> — landing page and selected projects
- <code>/about</code> — bio, experience, and education
- <code>/resume</code> — accordion-based experience and education view
- <code>/blog</code> — technical project write-ups
- <code>/blog/:postId</code> — individual posts

Project, experience, and blog content is kept in data modules under <code>src/data/</code>. Shared UI lives under <code>src/components/</code>.

The interface also includes page transitions, a persistent light/evening theme, custom cursor behavior, and decorative lantern effects.

## Run locally

~~~bash
git clone https://github.com/muhzain05/muhzain-portfolio.git
cd muhzain-portfolio
npm install
npm run dev
~~~

## Production build

~~~bash
npm run build
npm run preview
~~~

The production bundle is generated by Vite.
